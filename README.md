One line about office life, written to make the judge laugh: a meeting convened to decide whether it was necessary — and failing its own verdict. The program writes exactly that line to `/output/entry.txt` (80 bytes, no trailing newline), with a self-check that the line stays inside the 1–199 character gate.

> We scheduled a meeting to decide whether this meeting was necessary. It was not.

## Run it
